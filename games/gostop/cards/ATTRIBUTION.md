# 화투패 그림 출처 및 라이선스

이 폴더(`games/gostop/cards/`)의 SVG 파일 48개는 Wikimedia Commons 의
[Category:SVG Hwatu](https://commons.wikimedia.org/wiki/Category:SVG_Hwatu) 에서 받은 파일입니다.

- **라이선스**: [Creative Commons 저작자표시-동일조건변경허락 4.0 국제 (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/deed.ko)
- **저작자**
  - 원본 Hanafuda 그림: **Louie Mantia, Jr.**
  - 한국 화투 모양으로 색과 일부 선을 다시 그린 원본 세트: **Marcus Richert** —
    [File:Hwatu overview.svg](https://commons.wikimedia.org/wiki/File:Hwatu_overview.svg)
    (원 출처 http://www.marcusrichert.com/images/hwatu/)
  - 카드 한 장씩 분리·최적화: **Spenĉjo** (Wikimedia Commons)
- **변경 사항**: SVG 파일 내용은 **수정하지 않았습니다** (받은 그대로, 파일 이름도 Commons 와 같음).
  게임 화면에서 CSS 로 크기만 줄이거나 늘려 표시합니다 (가로:세로 비율 유지).
  같은 세트의 `*_flipped.svg`(뒤집은 변형) 4장은 쓰지 않아 넣지 않았습니다.
- **이 폴더 밖의 그림**: 보너스패 2장과 카드 뒷면은 원본 세트에 없어서 `games/gostop/art.js` 에서
  이 세트의 빨간 테두리 모양을 따라 새로 그렸습니다 (Commons 파일을 가공한 것이 아님).
- 위 SVG 파일들을 다시 배포하거나 고쳐 쓸 때도 CC BY-SA 4.0 조건(저작자 표시, 같은 라이선스)을 따라야 합니다.
  게임 코드(HTML/JS/CSS)는 이 그림과 별개의 파일입니다.

게임의 고스톱 첫 화면 아래에도 그림 출처를 표시합니다.
